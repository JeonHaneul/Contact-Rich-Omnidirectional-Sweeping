# Task documentation

For the task used in the training example, start with the [reference task specification](../example/Contact-Rich-Manipulation-Context/02_implementation/environments/PROF_REVISION_V0.md). It defines how the initial visible boxes are estimated, which contact signals reach the policy, and how a sweep is scored.

The [environment index](environments/README.md) traces the earlier task variants, including the move from single-object sweeping to clutter and wrist feedback. The [experiment plans](plan/) record the design decisions behind those variants. For setup and commands, see the [workspace README](../README.md).
